# 17. Eğitim Sonu

Eğitimde işlenen konuların özeti:

1. Python'un tanıtımı, temel kavramlar ve kurulum
2. Değişkenler, veri tipleri ve tip dönüşümleri
3. Karakter dizileri (string) ve metotları
4. Listeler, tuple, set ve dictionary
5. Operatörler
6. Koşullu durumlar (if / elif / else)
7. Döngüler (for / while, break / continue, comprehension)
8. Fonksiyonlar (parametreler, return, lambda, recursive)
9. Dosya yönetimi
10. Nesne yönelimli programlama (OOP)
11. Hata yönetimi (try / except / finally, raise)
12. Modüller
13. Veri tabanı (SQLite)
14. Python'un kullanım alanları
